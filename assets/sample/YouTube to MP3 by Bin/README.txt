YouTube → MP3 (By Bin)
===========================

사용법
------
1. ZIP 압축을 풉니다.
2. "실행.bat"를 더블클릭합니다.
3. 첫 실행 때 필요한 구성요소가 자동으로 준비됩니다.
4. 이후에는 "YouTube_MP3_Bin.exe"만 더블클릭하면 됩니다.
5. 유튜브 주소를 붙여넣고 "MP3 변환 시작"을 누릅니다.

필요한 것
----------
Windows 10/11 64비트와 인터넷 연결만 있으면 됩니다.
Python, VS Code, FFmpeg 수동 설치가 필요 없습니다.

첫 실행 시 자동으로 준비되는 구성요소
------------------------------------
- yt-dlp 공식 Windows 실행파일
- Deno Windows x64
- FFmpeg Windows essentials build

구성요소는 프로그램 폴더의 runtime\bin에 보관됩니다.
다음 실행부터는 다시 다운로드하지 않습니다.

저장 위치
---------
기본값: 사용자 음악 폴더\YouTube MP3

주의
----
다운로드 권한이 있는 콘텐츠에 사용하세요.
YouTube 이용약관과 저작권을 준수하세요.

인터넷 연결이 필요합니다.
외부 구성요소의 업데이트/배포 정책에 따라 첫 실행 또는 이후 실행 동작이 달라질 수 있습니다.
